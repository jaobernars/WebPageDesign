Introduction to Algorithms and Programming Logic

Anotações e material de apoio para Introdução a Algoritmos e Lógica de Programação, cobrindo os fundamentos do pensamento computacional e da construção de soluções passo a passo para problemas.

Resumo

Esta lecture é uma introdução aos fundamentos da lógica de programação, independente de linguagem. O conteúdo é estruturado de forma progressiva, partindo da definição de algoritmo e da construção de pseudocódigo e fluxogramas, passando por variáveis, tipos de dados, estruturas condicionais e de repetição, até chegar a estruturas de dados básicas como vetores e matrizes. O objetivo é desenvolver o raciocínio lógico necessário para decompor problemas em passos simples e traduzi-los em soluções computacionais, servindo como base para o estudo de qualquer linguagem de programação. Não é exigido nenhum conhecimento prévio de programação.
